# Open-source notices

Auno Player is distributed under **GPL-3.0-or-later**. See `LICENSE` for the
full license and `NOTICE` for attribution obligations.

## Source disclosure for APK releases

When publishing an APK, the release must include:

1. A copy of `LICENSE` and `NOTICE` in the source tree (already present).
2. A link to the **exact source commit** used to build that APK.
3. A statement that the source is available under GPL-3.0-or-later.

The publish helper must set the release body to include the source link for
the commit it publishes. Auno Player does not ship proprietary tracking,
ads, or premium gates.
